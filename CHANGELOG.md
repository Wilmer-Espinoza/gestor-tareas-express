# Changelog

## [1.0.0]

### Funcionalidades

- CRUD para crear, consultar, editar y eliminar tareas.
- Posibilidad de marcar tareas como completadas.
- Búsqueda de tareas por título.

### Correcciones

- Mejora de la validación para impedir títulos vacíos o formados únicamente por espacios.

### Pruebas

- Pruebas automatizadas mediante Jest.
- Validación de las operaciones principales del CRUD.

### Integración Continua

- Implementación de GitHub Actions.
- Instalación automática de dependencias.
- Validación automática de sintaxis.
- Ejecución automática de pruebas.
- Generación de reporte de cobertura.
- Publicación del reporte como artefacto.
